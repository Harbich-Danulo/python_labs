# Лабораторна робота №9: Паралельність, багатопроцесність та оптимізація

**Варіант №9: Облік спортивних результатів**

## 1. Опис проєкту
Проєкт присвячено експериментальному дослідженню продуктивності та оптимізації Python-додатку для предметної області «Облік спортивних результатів»:
- **Аналіз вузьких місць (Bottlenecks):** профілювання часу виконання через `cProfile` та споживання оперативної пам'яті за допомогою `tracemalloc`.
- **Базові реалізації (Baseline):** статистичні розрахунки (середнє, мінімум, максимум, дисперсія, стандартне відхилення, групування за категоріями, рейтинг) за допомогою стандартних циклів та структур даних Python.
- **Векторизація NumPy:** заміна циклів Python на векторизовані операції C-рівня (`array.mean()`, `array.std()`, `argsort()`).
- **Конкурентність та багатопоточність (threading):** дослідження впливу Global Interpreter Lock (GIL) на CPU-bound завдання та переваги `ThreadPoolExecutor` для I/O-bound операцій (паралельне завантаження файлів).
- **Справжній паралелізм (multiprocessing):** масштабування CPU-bound обчислень за допомогою `ProcessPoolExecutor` на різних конфігураціях ядер процесора (1, 2, 4, 8 workers).
- **Синхронізація (Synchronization):** демонстрація проблеми гонитви даних (Race Condition) при одночасному оновленні лічильника та її усунення за допомогою `threading.Lock`.
- **Кешування (Caching):** прискорення повторних важких запитів статистики та рейтингів за допомогою `functools.lru_cache` із керованою інвалідацією кешу (Cache Invalidation) при модифікації або додаванні результатів.

## 2. Структура проєкту (src-layout)
```text
Lab_09/
├── pyproject.toml                # Специфікація проекту, залежності та pytest/mypy
├── README.md                     # Документація користувача
├── REPORT.md                     # Академічний звіт (34 розділи, 60 питань)
├── report.html                   # HTML-версія для компіляції в PDF
├── Звіт_Лабораторна_9_Гарбіч.pdf # Фінальний офіційний звіт
├── data/                         # Каталог даних
├── src/
│   └── sports_opt/
│       ├── __init__.py           # Пакет sports_opt
│       ├── models.py             # Датакласи Athlete, Sport, SportResult
│       ├── analytics.py          # Генерація вибірок, baseline-розрахунки та NumPy-векторизація
│       ├── parallel.py           # Threading, Lock, ThreadPoolExecutor, ProcessPoolExecutor
│       ├── caching.py            # lru_cache, метрики hit/miss, інвалідація кешу
│       ├── profiling.py          # Модуль запуску cProfile та tracemalloc
│       ├── main.py               # Консольна демонстрація результатів профілювання
│       └── py.typed              # Маркер типізації PEP 561
├── benchmarks/
│   ├── benchmark.py              # Комплексний бенчмарк для 10k, 100k записів, різних workers
│   └── benchmark_results.csv     # Таблиця знятих експериментальних результатів у CSV
└── tests/
    ├── __init__.py
    ├── conftest.py               # Фікстури pytest
    ├── test_analytics.py         # Тести порівняння Python vs NumPy
    ├── test_parallel.py          # Тести потоків, процесів та захисту Lock
    ├── test_caching.py           # Тести кешування та інвалідації
    └── test_profiling.py         # Тести cProfile та tracemalloc
```

## 3. Встановлення та запуск

### 3.1. Встановлення залежностей
```bash
pip install -e .[dev]
```

### 3.2. Запуск демонстраційного сценарію
```bash
python -m sports_opt.main
```

### 3.3. Запуск комплексного бенчмарку
```bash
python benchmarks/benchmark.py
```

### 3.4. Запуск автоматизованих тестів
```bash
pytest -v
```

### 3.5. Перевірка типізації mypy
```bash
python -m mypy src tests
```
