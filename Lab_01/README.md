# Sports Tracker (Облік спортивних результатів)

Навчальний проєкт з дисципліни **«Професійний Python»** (Лабораторна робота №1).  
**Індивідуальний варіант №9:** «Облік спортивних результатів».

## Опис проєкту

Консольний Python-застосунок, побудований за сучасними стандартами розробки програмного забезпечення на Python із використанням архітектури `src-layout`, типізації (`type hints`), моделей даних на основі `dataclass`, відокремленої бізнес-логіки та інтерактивного консольного інтерфейсу (menu-driven interface).

### Основні можливості:
- Збереження даних спортсмена: ім'я, вид спорту, числовий результат, категорія.
- Додавання нового результату з клавіатури з валідацією даних (захист від порожніх рядків та від'ємних чисел).
- Пошук та фільтрація результатів за видом спорту.
- Пошук за кількома критеріями (вид спорту + категорія).
- Визначення найкращого результату (серед усіх або за конкретним видом спорту).
- Обчислення середнього результату та розширених статистичних показників (кількість, мінімум, максимум, середнє).
- Формування та виведення рейтингової таблиці учасників.
- Зручне інтерактивне текстове меню та режим автоматичної демонстрації.

## Встановлення (Installation)

1. Клонуйте репозиторій або відкрийте каталог проєкту у терміналі:
   ```bash
   cd lab1
   ```

2. Створіть віртуальне середовище:
   ```bash
   python -m venv .venv
   ```

3. Активуйте віртуальне середовище:
   - **Windows (PowerShell)**:
     ```powershell
     .venv\Scripts\activate
     ```
   - **Windows (Command Prompt)**:
     ```cmd
     .venv\Scripts\activate.bat
     ```
   - **Linux / macOS**:
     ```bash
     source .venv/bin/activate
     ```

4. Встановіть проєкт у режимі редагування (*editable installation*):
   ```bash
   python -m pip install -e .
   ```

## Запуск програми (Run)

### 1. Запуск через модуль Python:
```bash
python -m sports_tracker.main
```

### 2. Запуск через зареєстровану консольну команду:
```bash
sports-tracker
```

### 3. Автоматичний демонстраційний режим (без очікування введення користувача):
```bash
python -m sports_tracker.main --demo
```

### 4. Запуск автоматизованих тестів:
```bash
python tests/test_services.py
```
