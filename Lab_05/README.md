# Reliable Sports Importer (Лабораторна робота №5)

Індивідуальний варіант №9: **«Імпорт та експорт спортивних результатів»**.

## Опис проєкту
Надійний модуль потокового імпорту, валідації, фільтрації та атомарного експорту спортивних результатів із гнучкою конфігурацією у форматі YAML, ієрархією винятків domain-level, детальним журналюванням подій та підтримкою режимів strict/tolerant.

## Встановлення залежностей
```bash
python -m pip install pyyaml
```

## Запуск
```bash
python -m reliable_sports_importer.main
```
